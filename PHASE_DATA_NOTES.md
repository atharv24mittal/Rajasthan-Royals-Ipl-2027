# Public phase-statistics addendum — 17 November 2026

This addendum supplements (does not replace) the proprietary Stage 3 chase-pressure estimates.

## Scope and interpretation
- Powerplay: overs 1–6; middle: 7–15; death: 16–20.
- Economy figures are runs per over, not pressure scores.
- IPL 2026 phase samples and career aggregates are shown separately.
- Adam Milne's available phase figures are T20I and T20 Blast, not IPL; these are never labelled as IPL data.
- Career phase data for Deepak Chahar, Tushar Deshpande and Kuldeep Sen are from CricketViz; recent IPL 2026 data for Deepak, Tushar, Avesh and Trent Boult are from CricketStudio's ball-by-ball aggregation.
- Small phase samples are descriptive only. They should not be treated as stable player skill estimates or compared directly across competitions/seasons.
- No league baseline has been fabricated. A phase value is not a “versus baseline” result unless the matching baseline is actually sourced.
- Missing values remain N/A. Zero wickets in a phase is a true observed zero only where the source explicitly reports a non-empty sample.
